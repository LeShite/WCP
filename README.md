# WCP — Windows Copy Peer

Copia carpetas de perfil (Desktop, Documents, Downloads, Pictures) entre PCs Windows por LAN.

Licencia: MIT | Apache-2.0 (a elección del usuario)

## Instalación

```
pip install -e .
```

## Uso

```
python -m wcp
```
